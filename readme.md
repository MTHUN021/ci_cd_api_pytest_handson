# CI/CD API Pytest Hands-on

A sample project for learning API testing and CI/CD with Python and pytest.

## Overview
- API test examples using `pytest`
- CI/CD integration practice

## Setup
- Install dependencies:
    - `pip install -r requirements.txt`

## Run tests
- `pytest`

## Notes
- Designed for hands-on practice
- Keep tests simple and repeatable
- Use CI pipelines to automate test runs
